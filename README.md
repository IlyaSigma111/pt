# Интерактивная периодическая таблица элементов

Веб-версия периодической таблицы элементов в стиле ptable.com

## Возможности
- Полная таблица из 118 элементов
- Тёмная/светлая тема
- Просмотр свойств: атомная масса, радиус, электроотрицательность, плотность, температуры
- Слайдер температуры — показывает состояние вещества
- Переключение видов: простой, с названиями, с электронной конфигурацией
- Цветовая индикация значений свойств
- При наведении — подробная информация об элементе

## Как развернуть на GitHub Pages

1. Создай репозиторий на GitHub: https://github.com/new
2. Назови его `periodic-table` (или как хочешь)
3. Выполни в терминале (в папке Таблица):

```bash
cd "C:\Users\games\OneDrive\Рабочий стол\Таблица"
git remote add origin https://github.com/ТВОЙ_ЛОГИН/periodic-table.git
git branch -M main
git push -u origin main
```

4. В репозитории на GitHub зайди в Settings → Pages
5. В разделе Source выбери `main` branch и папку `/ (root)`
6. Нажми Save

Через 1-2 минуты сайт будет доступен по адресу:
`https://ТВОЙ_ЛОГИН.github.io/periodic-table/`

## Локальный запуск
Просто открой `index.html` в браузере.
